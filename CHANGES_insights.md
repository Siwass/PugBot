# PugBot Insights (финальная функция линейки v2.0)

## Что добавлено
- Раздел **📊 Аналитика** в главном меню (виден всем).
- Для владельца (OWNER_ID / `is_owner`): полный снимок метрик —
  администраторы, каналы, шаблоны, статусы постов, публикации за периоды,
  ожидающие автоудаления.
- Для остальных: единый тизер «станет доступна в следующих обновлениях» —
  без намёков на панель разработчика.
- Архитектура: `InsightsRepository` + `services/insights.py` + handler.
  Готово к расширению (графики, отчёты, экспорт) без переписывания UI.

## Файлы
- `database/insights_repository.py`
- `services/insights.py`
- `handlers/insights.py`
- `keyboards/menu.py` — кнопка
- `main.py` — роутер

Ничего из существующего UX/логики не изменено.
