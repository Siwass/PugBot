# Управление администраторами канала

Раздел ⚙️ Настройки → 👤 Администраторы теперь управляет
администраторами **подключённого Telegram-канала** пользователя
(не таблицей bot_admins проекта).

## Возможности
- ➕ Назначить администратора канала
- ➖ Снять администратора
- 📋 Список администраторов канала
- Проверка `can_promote_members` с инструкцией и кнопкой «🔄 Проверить права»

## Файлы
- `services/channel_admin_ops.py` — Bot API (list / promote / demote / rights)
- `handlers/settings.py` — UI и handlers раздела

Каналы, публикация, Insights, публичный доступ — без изменений.
